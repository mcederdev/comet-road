# Comet Road website

The public website for Comet Road, an arcade space racer for iPhone. GitHub Pages serves it at https://mcederdev.github.io/comet-road/.

| Page | URL |
| --- | --- |
| Landing page | https://mcederdev.github.io/comet-road/ |
| Press kit | https://mcederdev.github.io/comet-road/presskit.html |
| Support | https://mcederdev.github.io/comet-road/support.html |
| Privacy policy | https://mcederdev.github.io/comet-road/privacy.html |
| Terms of use | https://mcederdev.github.io/comet-road/terms.html |

The game itself lives in a separate private repository. `app-ads.txt` for AdMob lives at the root of mcederdev.github.io.

Press kit files (app icon, logos and a ZIP of them) are in `assets/press/`. Add screenshots there and on `presskit.html` when they exist.
